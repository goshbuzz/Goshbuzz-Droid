# Developer Certificate of Origin

This project uses **Developer Certificate of Origin 1.1 (DCO)** for all contributions. There is no CLA.

Every commit must carry a sign-off line matching the commit author:

```
Signed-off-by: Your Real Name <your@email>
```

Add it automatically with:

```bash
git commit -s -m "your message"
```

If you forgot, fix the last commit with `git commit -s --amend` (do not amend commits that are already
reviewed and merged into a shared branch without asking first).

## Why DCO instead of a CLA

A CLA would let the project relicense your work later without your involvement. The DCO does not. We accept the
extra administrative cost because a privacy project should not ask contributors to hand over rights they did
not intend to give.

## The canonical text

The authoritative DCO 1.1 text is published at <https://developercertificate.org/>. It is linked rather than
copied here so that this repository never carries a paraphrase of a legal document.

In short, by signing off you certify that:

1. You created the contribution in whole or in part, and you have the right to submit it under this project's
   license; or
2. The contribution is based on previous work that is covered by an appropriate open-source license, and you
   have the right to submit it under the same license; or
3. The contribution was provided to you by someone who certified (1) or (2), and you have not modified it.
4. You understand the contribution and its commit message are public and recorded indefinitely, and that the
   project or its successors may redistribute it under this project's license.

If you are contributing on behalf of an employer, you confirm you have permission to do so.

## Enforcement

A pull request without sign-off cannot be merged. This is mechanical, not personal.
